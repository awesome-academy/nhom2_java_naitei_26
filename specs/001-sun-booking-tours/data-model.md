# Data Model: SUN Booking Tours

This document describes the baseline PostgreSQL schema from `database/schema.sql`.

## Existing Baseline Entities

- **User**: Maps to `users` table. Represents Guests, Users, and Admins.
- **Social Account**: Maps to `social_account` table. Links OAuth providers (Google, FB, Twitter) to Users.
- **Bank Account**: Maps to `bank_account`. Stores user banking info. Present in baseline schema but temporarily unused by the application pending mentor confirmation.
- **Tour & Category**: `tour` and `category` tables. A category contains multiple tours.
- **Tour Departure**: `tour_departure`. Specific instances of a tour (dates, slots, price).
- **Place & Food**: `place`, `tour_place`, `food`. Locations visited during a tour and their associated food.
- **Booking**: `booking`. Tied to a User and a Tour Departure.
- **Booking Traveler**: `booking_traveler`. Passenger details for a booking.
- **Payment**: `payment`. Records internet banking transactions tied to a Booking and a Bank Account (`bank_account_id` currently unused pending mentor clarification).
- **Review**: `review`. Content and rating generated by Users exclusively tied to their Tour Bookings via `booking_id`.
- **Comments & Likes**: `comments`, `review_like`.
- **News**: `news`. Articles/news items published by admins/authors.

## Schema Modifications

No schema changes are required. The baseline schema correctly supports all approved requirements.
